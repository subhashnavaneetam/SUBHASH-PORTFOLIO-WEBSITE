- **Exact Reference Layout:** 1:1 replication of `monstermindcreations.work`'s 12 scenes with GSAP ScrollTrigger and Lenis smooth scrolling.
- **Jaydeep's High-Fashion Portrait (Scene 11):** Styled with high-contrast editorial grayscale and smooth hover-to-color transition.
- **Interactive Developer Terminal [CLI]:** Press `` ` `` (backtick) or `Ctrl + K` to run `whoami`, `education`, `skills`, `projects`, `contact`, and `vision`.
- **Audio Feedback System:** Pure browser Web Audio API oscillator feedback for clicks and success sounds (toggled with `SOUND ○` in the header).
- **Dual Mode:** Dark Void (default) & Light Paper themes with persistent local storage.
